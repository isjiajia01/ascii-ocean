# ASCII Ocean

一个用字符绘制的交互式海洋：锦鲤池、蝠鲼与深海水母。单个 HTML 文件，无需安装依赖，直接在浏览器中打开 `index.html` 即可运行。

- 按 **1 / 2 / 3** 切换场景，按 **S** 切换块面和线墨风格。
- 点击画面投食、激起涟漪或释放光波；在锦鲤池中移动鼠标可以吸引鱼群。
- 也可以通过 `?scene=koi`、`?scene=manta` 或 `?scene=jelly` 指定初始场景。
